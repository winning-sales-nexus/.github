# nexu

Inteligência de vendas para PME brasileira. O nexu lê o CRM, as reuniões, o WhatsApp e o e-mail e
mostra ao gestor e ao vendedor como estão a meta, o funil e cada negócio — com o trecho que sustenta
cada leitura.

## Produto

| Repositório | O que é |
| --- | --- |
| [nexu-api](https://github.com/winning-sales-nexus/nexu-api) 🔒 | API e workers: identidade multiempresa, ingestão de webhooks, e-mail e WhatsApp (NestJS + Kysely + AWS) |
| [nexu-fe](https://github.com/winning-sales-nexus/nexu-fe) 🔒 | Painel web (React + TS) |
